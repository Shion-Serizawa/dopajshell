# Security Policy

If you find a security issue in dopajshell, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/Shion-Serizawa/dopajshell/security/advisories/new)
instead of opening a public issue.

脆弱性を見つけた場合は、公開の Issue ではなく、上のリンク（GitHub の非公開の脆弱性報告）から報告してください。

Only the latest release is supported.
